<p align="center">
  「做个鸟测评」面向那些重复、无意义，却又不得不完成的在线测评，<br>
  例如秋招、春招中的在线笔试等。
</p>

<p align="center">
  它通过获取屏幕内容，交给 Codex 回答，<br>
  再通过预先定义好的<em>鸟鸣声</em>传递答案，以规避检测系统。
</p>

## 适用场景

以下面向浏览器内进行的在线测评，不包含要求安装本机考试客户端、本地监考程序或在特定线下场所的情况。

| 浏览器内的监测方式 | 方案效果 |
| --- | --- |
| 全屏录制 | ✅ 常规答题过程无需展示聊天窗口或文字答案，通过鸟鸣反馈。 |
| 正面摄像头录像 | ✅ 无需拿手机拍题、查看其他屏幕或口述问题。 |
| 手机第二机位录像 | ✅ 直接获取屏幕内容并通过鸟鸣反馈，无需拿手机拍题或查看额外的答案设备。 |
| 麦克风录音 | ✅ 无需口述问题，以鸟鸣代替语音答案，减少直接暴露题目和选项内容。 |
| 按键识别 | ✅ 全程使用鼠标提问和收集截图，无需 Ctrl+C、Ctrl+V 等键盘快捷键，不产生这类组合键的按键记录。 |
| 切屏／窗口焦点检测 | ✅ 常规提问过程无需切换页面或打开聊天窗口。 |
| 系统音频录制 | ✅ 通过鸟鸣次数传达选项，音频中无需朗读题目或答案文字。 |
| 鼠标操作记录 | ✅ 使用简单的鼠标点击完成提问，无需复制题目、切换聊天窗口或粘贴答案。 |
| 人工逐帧放大复核 | ⚠️ 不保证通过人工复核，也不保证作答行为不会被识别或质疑。 |

## 使用流程

**启动「做个鸟测评」，确认托盘显示就绪 → 在题目页面执行鼠标操作 → 听取鸟鸣答案**

| 使用场景 | 操作方法 |
| --- | --- |
| 题目在一屏内显示完整，直接提问 | **左键三连击**，等待鸟鸣答案。 |
| 题目一屏内显示不全，需要提交两屏或更多画面 | 在第一屏**按住右键＋左键三连击**（触发完成后即可松开右键），即暂存当前画面，滚动到下一页重复该操作，直到最后一页时，**不按右键，仅左键三连击**，所有画面会一起提交，随后等待鸟鸣。 |

**鸟鸣 1–6 次对应按出现顺序排列的选项 A–F；无法回答时播放失败提示音。** 答案鸟鸣来自[十姊妹](https://zh.wikipedia.org/wiki/十姊妹)，每次回答会随机选取叫声片段，并有轻微的音高、音量变化，因此声音不完全一致，按鸣叫次数辨认答案即可。可通过托盘「试听提示音」提前熟悉声音。

<details>
<summary>一屏有多道题或题目跨屏时，会回答哪一道？</summary>

- **先合并画面，再选题。** 多张截图按提交顺序阅读，衔接跨屏内容并结合重叠部分；同一道题的题干、选项和材料可以分布在不同截图中。
- **只选第一道符合条件的题。** 按自然阅读顺序，选择第一道题干、全部选项及必要材料完整，且有 2–6 个选项的单选题。鼠标位置只决定截取哪个屏幕，不用于指定题目。
- **不符合条件的题会跳过。** 例如第一道题不完整、是多选题或有 7 个选项，会继续寻找后面的合格题目；不会删减选项来凑数。所有截图中都没有合格题目时，播放失败提示音。
- **选定后不会换题。** 即使后面的题更容易，也只回答已选中的题；无法确定唯一正确选项、没有正确选项或有多个正确选项时，播放失败提示音。

</details>

## 快速开始

1. 从 [Releases](https://github.com/Circloud/QuizChirp/releases) 下载对应平台的应用包并完整解压。
2. Windows 打开 `QuizChirp.exe`；macOS 将 `QuizChirp.app` 放入「应用程序」后打开，按提示授予屏幕录制和输入监听权限。
3. 按托盘／菜单栏提示，按需下载 Codex 并使用 ChatGPT 登录。显示「就绪」后即可使用。

<sub>当前构建未使用可信发布者签名，macOS 版未公证，首次打开可能遇到系统安全提示。</sub>
